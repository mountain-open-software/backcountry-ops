- [ADR 0001 — Workspace boundaries and verification](0001-workspace-boundaries-and-verification.md): accepted.

Use filenames such as `0001-short-decision-title.md` and include:

- Status: proposed, accepted, rejected, or superseded.
- Context and the problem being addressed.
- Decision and alternatives considered.
- Consequences, compatibility implications, and follow-up work.

Link superseded decisions to their replacements. Keep unresolved questions in the [product vision](../../product/vision.md#15-architectural-decisions-to-validate) until there is enough evidence to decide.
